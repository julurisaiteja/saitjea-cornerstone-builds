# sai-cornerstone-builds

Diamond storefront (batch 2). Next.js App Router + Tailwind.

## Local

```bash
npm i
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Notes

- Mock cart / Stripe-style checkout (no real payments)
- English product brand UI only
